## 制作检查重点

| 检查项 | 要求 | 适用段落 |
|---|---|---|
| 标题情绪 | 旧星星委屈感要清楚，但不能过度悲伤。 | T |
| 玩偶规则 | 章鱼、独角兽、旧星星、旧玩具群像不眨眼、不张嘴、不自主运动；说话用配音、气泡、思思代演、魔法可视化或后期效果呈现。 | T-L |
| 思思性格 | 兴奋但不熊，开心、认真、文静底色仍成立。 | S-L |
| Sc01 功能 | 快速建立“新玩具很开心”，为 Sc02 旧玩具被忽略做铺垫。 | S |
| 精灵活动 | 情公主、孔雀/灵公主、时钟女孩可以自由活动和施法，但不能替思思完成成长动作。 | B-L |
| 情绪逻辑 | 先让思思开心忽略，再由情公主发现和接住情绪，最后由思思主动道歉并提出一起玩。 | A-J2 |
| 光效分区 | 情公主粉光、孔雀绿光、时钟女孩金光、旧星星治愈暖金光要区分。 | B-J2 |
| 音乐音效 | 音乐音效不纳入团队制作任务；如甲方/后期已有音频素材，仅由 Esdeath 在剪辑合成阶段对接使用。 | T-L |
| 拼接接口 | 段间按提示词顺序拼接，注意景别和运镜双跳，避免电视剧感拖节奏。 | T-L |
